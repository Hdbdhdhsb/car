当前不影响运行，但别照着它接线。

## 5. 空闲资源（可扩展）

**FPC1（0.5mm 14P）引出的 12 根 GPIO —— 当前固件完全未使用：**

| FPC1 脚 | 端口 | U16 脚 | 可用复用功能（摘自官方手册） |
|---:|---|:--:|---|
| 2 | P4.0 | 31 | PWMC1P / MOSI_3 / I2S_Data_4 |
| 3 | P6.5 | 33 | PWMA3N_3 / PWMC3N / MOSI2 |
| 4 | P6.6 | 34 | PWMA4P_3 / PWMC4P / MISO2 |
| 5 | P6.7 | 35 | PWMA4N_3 / PWMC4N / SCLK2 |
| 6 | P9.0 | 36 | **PWMF5_3** / PWME1P_2 / RxD7_3 / T18 |
| 7 | P9.1 | 37 | **PWMF6_3** / PWME1N_2 / TxD7_3 |
| 8 | P9.2 | 38 | **PWMF7_3** / PWME2P_2 / RxD8_3 |
| 9 | P9.3 | 39 | **PWMF8_3** / PWME2N_2 / TxD8_3 |
| 10 | P9.4 | 40 | PWME3P_2 / S3SS_4 |
| 11 | P9.5 | 41 | PWME3N_2 / S3MOSI_4 |
| 12 | P9.6 | 42 | PWME4P_2 / S3MISO_4 |
| 13 | P9.7 | 43 | PWME4N_2 / S3SCLK_4 |

> **P9.0-P9.3 是 PWMF 组的 4 个独立通道**（不像 PWMA/PWMC 那样 P/N 互补），
> 同组同频 —— **舵机 50Hz 场景下正好是 4 路独立舵机输出**，够一个二轴云台。
> 这基本就是 FPC1 预留的用途。
>
> 记名对照：官方手册写作 `PWMF5_3 / PWMF6_3 / PWMF7_3 / PWMF8_3`
> （P9.0-P9.3 是 PWMF5-8 的第三组映射），逐飞库写作
> `PWMF_CH1_P90 / CH2_P91 / CH3_P92 / CH4_P93`。同一批脚，两套编号。

其余可用：UART7（PA.4/PA.5，已引到 U18 接口）、CN6 开关输出（PA.6）、
U16 上有约 40 个完全空闲的 IO 脚但未引出。

## 6. 待确认

- [ ] **FPC1 的真实用途**：12 根 GPIO 全部空闲，疑似预留屏口或云台口（见 §5 推断）。
- [ ] **DMA 占脚**：逐飞库 `zf_device_mt9v03x_dma.h` 注释称「FIFO 引脚禁止修改，
      否则摄像头 DMA 会占用 **P4.5 / P3.6**」。板子上这两脚（U16.93 / U16.53）**未连线**。
      需确认当前 DMA 配置是否真的需要它们。
- [ ] **CN6 驱动能力**：`PA.6 → Q5(CJ2302) → CN6.1`，Q5 漏极接 **VCC(3.3V)**、
      源极接 CN6.1（源跟随器接法），对外是**一路 3.3V 弱开关**，无限流。
      驱动蜂鸣器勉强，**带不了紫外激光管**（激光管必须恒流驱动）。
- [ ] **U1（STC32G12K128-QFN48）的端口名**未还原：本仓库固件是上位机侧，
      资料里也没有该封装的引脚表。需要下位机固件时再补。

## 8. 对「打靶留痕」的硬件结论

| 需求 | 板子现状 |
|---|---|
| 紫外照射驱动 | ❌ **全板无 LASER/UV 网络**。最接近的 CN6 是 3.3V 弱开关（见 §6），不能直接驱动激光管 |
| 云台 | ⚠️ 有现成接口但未引出：只有一路舵机（H1，在下位机上）。**FPC1 的 P9.0-P9.3 可出 4 路独立 PWM**，是二轴云台的落点 |
| 主控合规 | ✅ U16 = STC32G144K246，符合「官方指定 STC32G144」 |
| 单摄像头 | ✅ 只有一个摄像头接口（U15） |
| 无其它光电管 | ✅ 全板无光电管/灰度传感器 |

> 恒流驱动级对紫外激光管是必须、对 UV LED 也是最优工况 ——
> **一套恒流电路可同时覆盖「激光管」和「UV LED」两种口径**，
> 不必等规则口径确认就能先做。
